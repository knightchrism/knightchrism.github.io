Data handling

Data security

How GeoKnight GIS handles client data during a project. This describes our practices; it is not a claim of any certification or formal compliance program.

Kept private

Client data is used only for your project. It is not published, shared with other clients, or used in public demos without your written permission.

Never resold

Your data is never sold, rented or licensed to anyone.

Deleted on request

At the end of a project, or any time you ask, working copies of your data are deleted and we confirm by email.

Secured systems

Processing happens on access-controlled, password-protected systems, and file transfers use encrypted channels (such as HTTPS or SFTP).

Source data untouched

Your source data is never overwritten. Fixes are delivered as proposed, logged changes that a human reviews and approves.

Local AI option

AI-assisted review can run on a local LLM (Ollama) so data does not leave controlled machines. Cloud AI services are used only if you agree.

Licenses and attribution

Data licenses and sources are tracked for every layer we work with.

Questions

If your organization has specific data-handling requirements, raise them before the project starts and we will discuss whether and how we can meet them. Email geoknight0015@gmail.com.
