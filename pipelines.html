How we work

The data pipelines we built

A data pipeline is an assembly line for information. It collects records from public sources, cleans and checks them, joins them together, and turns them into maps, reports and tools you can trust. The same steps run the same way every time, so the result can be repeated and checked.

Jacksonville Property & Flood Risk

  • What it pulls in: The Duval County Property Appraiser tax roll, parcel maps and sales (certified 10-13-26) and FEMA flood zones for Duval County.
  • What it makes: One checked table joining each property’s value, sales and flood zones, a map explorer of address and values, and an AI layer that answers plain-English questions about property, flood risk and sales.
  • How it stays accurate: Broken parcel shapes are repaired on a copy, so the originals are never edited. Every FEMA flood zone is accounted for, and tested data models stop the build if a check fails. The AI layer can only read, never change, the data.

Tech used

  • PostgreSQL / PostGIS: a database that understands maps, so it can answer questions like “which homes touch this flood zone?”
  • Python: the programming language that does the downloading, cleaning and checking.
  • GeoPandas: a Python toolkit for reading map files and fixing broken shapes.
  • FEMA NFHL: FEMA’s official National Flood Hazard Layer, the flood-zone maps used for insurance.
  • dbt: turns raw tables into clean, tested ones and stops if a check fails.
  • Leaflet: draws simple, fast interactive maps in your web browser.
  • MCP: a standard “plug” that lets an AI assistant look things up in the database, read-only.
  • Ollama: runs an AI model privately on our own machine, so questions and data don’t leave it.

OpenAtlas

  • What it pulls in: U.S. Census boundaries (2024) and American Community Survey 2020–2024 figures for seven Northeast Florida counties, plus map files a user uploads.
  • What it makes: A 3D globe and dashboard where your own data sits next to Census data and can be exported to Excel, Shapefile, GeoPackage, FileGDB or a one-page PDF.
  • How it stays accurate: Each Census load is logged. Uploads are checked, put into a standard map coordinate system and labeled, and sample data is always marked synthetic.

Tech used

  • Dagster: a scheduler that runs each step in order and keeps a log of every run.
  • PostgreSQL / PostGIS: a database that understands maps, so it can answer questions like “which homes touch this flood zone?”
  • FastAPI: the web service that hands data from the database to the map and to exports.
  • MapLibre: draws the interactive 3D globe in your web browser.
  • Census API: the U.S. Census Bureau’s official online source for population and housing figures.
  • ArcGIS REST: the standard way government agencies publish map data online; we read from it politely and never change it.

Water-management open data & quality check

  • What it pulls in: 15 public map layers from the St. Johns River Water Management District (727,495 features), including groundwater monitoring stations.
  • What it makes: A checked copy of the layers as fast map tiles, and a quality report: 850 stations checked against 8 rules, with 940 findings logged for review.
  • How it stays accurate: The source data is copied untouched. Problems are listed for a person to review, never fixed silently. Not affiliated with or endorsed by SJRWMD.

Florida Census data pipeline

  • What it pulls in: U.S. Census Bureau American Community Survey 5-year figures for all 67 Florida counties.
  • What it makes: Clean, tested county tables for market analysis, which an AI assistant can query.
  • How it stays accurate: Margins of error are kept, and county totals are checked against the state total.

Tech used

  • Census API: the U.S. Census Bureau’s official online source for population and housing figures.
  • Python: the programming language that does the downloading, cleaning and checking.
  • DuckDB: a small, fast analysis database that runs on one machine.
  • dbt: turns raw tables into clean, tested ones and stops if a check fails.
  • MCP: a standard “plug” that lets an AI assistant look things up in the database, read-only.

Print-ready map sheets

  • What it pulls in: OpenStreetMap and public map layers.
  • What it makes: Topographic-style 1:50,000 sheets with legend, scale bars and grid. The Jacksonville sample sheet has 781 labels with 0 quality failures.
  • How it stays accurate: A built-in check confirms that no labels overlap before a sheet is exported.

Tech used

  • Rust: a fast, reliable programming language used for the label-placement engine.
  • Vector PDF / SVG: print files that stay sharp at any size.

Privacy and what we never publish

  • Records exempt from public disclosure under Florida law are removed.
  • Owner names and contact details are removed before anything reaches a public map.
  • We publish maps, summaries and screening estimates, not bulk copies of records.
  • Estimates are for screening only: not a survey, inspection, appraisal or legal determination.
