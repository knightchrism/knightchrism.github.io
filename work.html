Self-initiated demonstration on public data · jax-property-intelligence

Jacksonville Property & Flood Risk

County property records arrive messy: broken map shapes, duplicate addresses, mismatched ZIP codes. This pipeline cleans them up, matches each property to its FEMA flood zone and sales history, and flags anything that doesn't add up, so you can trust the numbers before you buy, insure or lend. You get one clean property database and an interactive map. All 12,288 FEMA flood zones were loaded with none lost.

Built with: PostGIS, Python, GeoPandas, dbt, Leaflet

Self-initiated demonstration on public data · sjrwmd-geodata-qc

Water-Monitoring Data Quality Check

Public map data often has gaps: missing IDs, missing locations, blank fields. This tool automatically checks every record against a clear list of rules and writes down each problem it finds, without changing the original data. You get a findings report and a map to review them. It checked 850 water-monitoring stations against 8 rules and logged 940 findings.

Built on publicly available SJRWMD open data. Not affiliated with or endorsed by SJRWMD.

Built with: GeoPandas, ArcGIS REST, Leaflet

Self-initiated demonstration on public data · census-pipeline

Florida Market-Analysis Pipeline

Census numbers are easy to misread: blank values counted as zero, error margins dropped, county totals that don't match the state. This pipeline pulls the data for all 67 Florida counties, keeps the margins of error, flags unreliable estimates, and checks that the counties add up to the state total. You get trustworthy county figures ready for market maps and reports.

Built with: Python, Census API, DuckDB, dbt
