Florida Market-Analysis Pipeline

US Census ACS data for Florida's 67 counties → DuckDB → tested dbt models → governed market metrics with margins of error, ready for market-analysis maps and reports.

Repository

Problem

Market analysis for real estate and insurance needs trustworthy county-level demographics and income figures, with the statistical caveats intact. Raw Census API pulls are easy to get wrong: sentinel codes counted as values, margins of error dropped, and county totals that don't add up to the state.

Key decisions

  • Quality gates before load. Row counts, columns, duplicate GEOIDs and parse rate are checked before anything is written.
  • Idempotent loads. Each (year, state) is replaced atomically in DuckDB, so re-running is safe.
  • Sentinels → NULL + flag. Census “no value” codes become NULL with the code kept in a flag column.
  • Respect the statistics. 90% margins of error kept, CV > 0.30 flagged as unreliable, growth only across non-overlapping windows.
  • Reconciliation test. A custom dbt test proves the 67 counties sum to the official state total.
  • Governed metrics. semantic/metrics.yml defines formula, grain and caveats, compiled to parameterized SQL, and exposed through a read-only query layer that AI assistants can use safely.
  • Scales by config. All 50 states is a change to config.yaml.
