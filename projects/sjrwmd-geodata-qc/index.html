SJRWMD GeoData Quality Inspector

GIS · Spatial Data · AI Integration Engineering

Rule-driven QA/QC for public groundwater-station GIS data: findings you can filter, inspect and export, with the source data left untouched.

Live dashboard →Repository →

Problem

Public GIS services are published as-is: records can be missing identifiers, geometry, or attributes that downstream users rely on. Fixing data you do not own is not an option, but documenting issues is. The goal: an automated, repeatable QA/QC workflow that pulls the public groundwater-station layer, applies configurable rules, writes every finding to an audit trail, and lets a reviewer explore them on a map, without changing the source data.

Data sources

  • St. Johns River Water Management District public ArcGIS REST Feature Service: Active Groundwater Monitoring Network, Water Level Event Type
  • OpenStreetMap basemap for the dashboard

Architecture

Key decisions

  • Rules as config, not code. All 8 rules live in config/qc_rules.json with id, field, check type, severity and an interpretation, so they can be reviewed and changed without touching Python.
  • Raw download preserved. The original data is saved as-is and never modified by the QA/QC process.
  • Findings, not verdicts. Results are project-defined review findings, not confirmed errors: a record missing UTM attributes can still have valid lat/long and point geometry.
  • Severity tiers. Critical (identity, geometry), warning (county) and info (optional attributes) keep reviewers focused.
  • Auditable outputs. Every finding is written to CSV/JSON; the dashboard filters by rule and severity, shows original values and exports filtered CSV.
  • Static hosting. The dashboard is plain HTML + Leaflet on GitHub Pages, with no server to maintain.

Rules engine: evaluate_rule (Python / GeoPandas)
def evaluate_rule(rule):
    check = rule["check"]
    fields = fields_for_rule(rule)

    if check in ("required", "missing"):
        return missing(gdf[fields[0]])

    if check == "unique":
        series = gdf[fields[0]]
        return ~missing(series) & series.duplicated(keep=False)

    if check == "geometry_present":
        return gdf.geometry.isna() | gdf.geometry.is_empty

    if check == "geometry_valid":
        return gdf.geometry.notna() & ~gdf.geometry.is_empty & ~gdf.geometry.is_valid

    if check == "missing_any":
        result = pd.Series(False, index=gdf.index)

        for field in fields:
            result = result | missing(gdf[field])

        return result

    raise ValueError(f"Unsupported check: {check}")
