Water-Monitoring Data Quality Check (public SJRWMD data)

Automatically checks publicly available water-monitoring map data for missing or inconsistent information and gives you a clear list of every problem, without changing the original data.

Live dashboard Repository

The problem

Public map data is published as-is. Records can be missing an ID, a location, or details people downstream rely on. You can't fix data you don't own, but you can document the problems so they're easy to review and act on.

What it does

  • Downloads publicly available groundwater-station open data published by the St. Johns River Water Management District (SJRWMD) and keeps an untouched copy.
  • Checks every record against 8 clear rules, such as missing IDs, missing locations or blank county names.
  • Sorts each problem by how serious it is: critical, warning or informational.
  • Treats results as items to review, not verdicts, since a record can still be usable.

What you get

  • A findings report (spreadsheet and data file) listing every issue.
  • A map dashboard to filter problems by rule and severity and export them.
  • Rules kept in a simple settings file, so they can be changed without new code.
  • Nothing to maintain: the dashboard is a plain web page.
