Capability statement

GeoKnight Geospatial Information Services

Custom GIS web applications: interactive maps, dashboards and data tools built for your workflow.

GeoKnight GIS is a geospatial consultancy based in Jacksonville, Florida and serving clients anywhere, building custom GIS web applications: interactive web maps, dashboards and map-based tools, backed by tested data pipelines.

Core competencies

  • Custom GIS web applications and map-based tools
  • Interactive web maps and dashboards (search, filters, charts)
  • 3D globes, terrain and visualization
  • Utility network analysis and tracing
  • Property and FEMA flood-risk data integration in PostGIS
  • Data pipelines and open-data publishing (ArcGIS REST, Census, dbt, DuckDB, PMTiles)

Differentiators

  • Built around your data and workflow, with a hand-off and walkthrough
  • Source data is never overwritten; data loads are logged and tested
  • You own the deliverables and source code
  • Works with ArcGIS data and open-source tools (PostGIS, QGIS, DuckDB)
  • Local LLM option so data can stay on your own machines
  • Founder-led: former GS-13 Geographer (U.S. Army Geospatial Center), 23+ years building and validating authoritative spatial data
